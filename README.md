# PerManah

Sistem manajemen perpustakaan (admin, petugas, anggota).

## Fitur Utama
- Manajemen buku (stok, tersedia, harga, kategori)
- Peminjaman, pengembalian, dan penandaan buku hilang
- Denda keterlambatan dan ganti rugi
- Laporan dan ekspor (print/PDF)
- Manajemen anggota dan pembayaran

## Setup Singkat
1. Salin `.env.example` menjadi `.env`
2. Atur koneksi database
3. Jalankan migrasi dan seeder
4. Jalankan aplikasi

Catatan: file `.env` tidak disertakan di repo.
